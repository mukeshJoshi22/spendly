    ⎿  (eval):1: command not found: pip                                         

⏺ The issue is that each ! command runs in a separate shell, so the source 
  cenv/bin/activate from one command doesn't carry over to the next. The venv
  isn't active when you run pip install.

  Fix: chain the commands in one line:

  ! source cenv/bin/activate && pip install -r requirements.txt

  Or use the venv's pip directly without activating:

  ! cenv/bin/pip install -r requirements.txt
